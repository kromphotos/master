Данный проект позволяет хранить данные в виде дерева и выполнять с ними операции: удаления узла, добавления узла(корневого и дочернего), редактирования узла, просмотра информации об узле и просмотра всех данных в базе.
## Стек технологий
* Java 8
* GWT 2.7
* Ant
* PostgreSQL
* MyBatis
## Структура проекта
Проект организован следующим образом:

**`src/`** - исходный код. Основной пакет  - `com.kristina.gwttreecrud`, внутри него три подпакета:

**`src/client/`**  - клиентская часть на GWT. Здесь реализован паттерн MVP. Каждый компонент лежит в своей подпапке: `tree/`  - дерево узлов, `nodeinfo/`  - карточка информации, `nodeadd/`  - форма добавления, `nodeactions/` - панель кнопок, `allnodes/`  - таблица всех узлов. В папке `events/`  - глобальный ивент бас (`AppEventBus`) и все события приложения. Также здесь находятся RPC-интерфейсы (`GwtService`, `GwtServiceAsync`), синглтон для доступа к сервису (`AppGwtService`) и точка входа приложения (`GwtTreeCRUD.java`)

**`src/server/`**  -  серверная часть. В подпапке `dao/`  - классы для работы с базой данных (`TreeNodeDao`, `TreeNodeDaoImp`), в `mapper/`  - MyBatis-маппер (`NodeMapper`). Также здесь лежат RPC-реализация (`GwtServiceImpl`), сервис (`TreeNodeService`) и его реализация (`TreeNodeServiceImp`), которая открывает сессии MyBatis, вызывает DAO и обрабатывает ошибки

**`src/shared/`**  - классы, доступные и клиенту, и серверу. Здесь модель узла дерева (`TreeNode`) и исключение, написанное мной (`TreeCrudProgramException`)

**`sql/`**  -  SQL-скрипты для создания таблицы `tree_node`, последовательности `tree_node_SEQ` и тестовых данных.

**`lib/`**  -  все сторонние библиотеки: GWT (`gwt-user.jar`, `gwt-servlet.jar`), MyBatis, JDBC-драйвер PostgreSQL, Servlet API. Подключаются через `build.xml`

**`resource/`**  -  конфигурационные файлы: `mybatis-config.xml` (настройки MyBatis), `NodeMapper.xml` (SQL-запросы), `db.properties` (логин/пароль и URL базы данных)

**`war/`**  -  web-ресурсы приложения: HTML-страница (`gwtTreeCRUD.html`), CSS-файл со стилями и `WEB-INF/web.xml`

**`build/`** — папка сборки, создаётся Ant-ом автоматически. После сборки здесь появляется готовый WAR-файл в подпапке `war/`

**`build.xml`** — Ant-скрипт для сборки проекта (компиляция Java-классов, компиляция GWT-модуля, упаковка WAR)

**`README.md`** — документация проекта

## Использование

1) Настройка базы данных
	1. Запустите PostgreSQL и создайте базу данных
	2. Выполните SQL-скрипты из папки sql
	3. Убедитесь, что в файле `db.properties`  указаны **ваши** логин/пароль от БД
2) Сборка проекта
	1. Убедитесь, что установлены Java 8 и Apache Ant , в корне проекта есть файл `build.xml`
	2. Запустите ant для сборки(перед этим очистите предыдущую сборку ant clean)
3) Запуск приложения
	1. Запустите приложение через Ant  или разверните WAR-файл из `build/war/` на сервере приложения
	2. Откройте приложение в браузере


## Функционал приложения

Интерфейс состоит из **четырех** частей:
***Дерево узлов*** - отображает все узлы в иерархическом порядке, при наличии потомков узла, можно их посмотреть нажав на кнопку "+". Дерево поддерживает ленивую загрузку
***Карточка с информацией об узле*** - при нажатии на имя узла в дереве в карточке появляется информация об айди, айди родителя, айпи и порта ноды
***Таблица всех узлов*** - содержит информацию обо всех узлах из базы данных, обновляется при любых изменениях у узла
***Панель управления*** - позволяет по нажатию соответствующей кнопки добавлять корневую ноду, добавлять родительскую ноду, редактировать и удалять узлы. При удалении родительской ноды также удаляются ее потомки!

**Ограничения:** пустые значения не допускаются
